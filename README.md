## Problem Statement
Accessing reliable healthcare services—such as booking doctor appointments, finding nearby clinics, or calling an ambulance in an emergency—is often fragmented and time-consuming. Patients struggle to navigate different platforms for various healthcare needs, leading to delays in critical care.

## Solution Overview
SwasthyaCare is a comprehensive, centralized healthcare platform connecting patients with doctors, clinics, and ambulance services anytime, anywhere. 
Key features include:
- Find and book appointments with nearby Doctors.
- Explore nearby Clinics and Ambulances on an interactive interface.
- Comprehensive dedicated Dashboards for Patients, Doctors, Clinics, Ambulances, and Administrators.
- Floating AI-Assistant Chatbot for instant support and platform navigation.

## Setup Instructions
To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/sumaiahanjumanjum-rgb/Smarthealth--Hackmatri2026.git
   ```
2. Navigate into the project directory:
   ```bash
   cd SwasthyaCare-main
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
